# Component-specific data-rights assessment

| Component | Access position | Public-release treatment | Status |
|---|---|---|---|
| Original DMO schedules | Publicly accessible government publications; original publisher terms govern | Do not redistribute; provide official links, source identifiers, and checksums | Appropriate for staged release; reuse terms require depositor confirmation |
| Original NBS IGR and FAAC publications | Publicly accessible government publications; original publisher terms govern | Do not redistribute; provide retrieval instructions and source records | Appropriate for staged release; reuse terms require depositor confirmation |
| Derived 216-row analytical panel | Researcher-constructed values from public official sources | Included provisionally for computational reproducibility | Confirm redistribution treatment before public deposit |
| Derived results and figures | Researcher-produced analytical outputs | Included | Author-controlled, subject to confirmation of any upstream restrictions |
| R and Julia source code | Researcher-authored code | MIT license | Confirmed for author-controlled code |
| Source manifests and checksums | Researcher-authored documentation of public records | Included | Appropriate for release |

This is an operational assessment, not legal advice. Public web access does not itself establish a right to redistribute the original files. If any source term restricts redistribution of the derived state-year values, keep those files in a controlled reviewer-access archive and retain the code, official links, manifests, and instructions publicly.
